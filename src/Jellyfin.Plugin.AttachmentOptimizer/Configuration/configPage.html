Extraction

Use one FFmpeg process with one -dump_attachment option per missing attachment. Existing cached files are not overwritten.

Deduplication

Store extracted bytes by SHA-256 and reuse them across media sources.
Avoid physical copies in Jellyfin's per-media attachment folders when the filesystem supports hard links. A verified copy is used as fallback.

Automatic cleanup

Clean only files and manifests managed by this plugin. Recently used and active media sources are skipped.
